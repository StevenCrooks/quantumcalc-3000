# QuantumCalc 3000 • Photorealistic Pro

Next-gen multi-function quantum calculator with photorealistic skin and real 3D PBR engine.

**Live Demo:** `https://multi-function-quantum-calculator.onrender.com` (after Render deploy)

### ✨ Features - Photorealistic Skin
- **Three.js r160 PBR**: Real lights, shadows, metalness 0.7, roughness 0.25
- **Glassmorphism UI**: Blur 24px, depth, reflections, inset highlights
- **Better 3D**: 80x80 high-res grid (6400 verts), vertex colors by height, 12k tris
- **Interactive**: Wireframe toggle, Top/Iso/Side views, auto-rotate, OrbitControls
- **Export**: PNG for TikTok/IG, LaTeX, JSON history

### 🧮 Calculator Functions
- Analyzer: sin(x*1.5)*cos(y*1.2)+z*0.3 with real evaluation
- 3D Grapher with random functions
- AI Solver, Unit Converter
- History + Export
- 100% Offline - PWA installable
